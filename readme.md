
# 🔐 Password Generator with Password Strength Checker

## 📌 Project Description

The Password Generator with Password Strength Checker is a Python-based desktop application developed using Tkinter. It generates random passwords according to user-selected length and character types. The application also estimates password strength and allows users to copy generated passwords to the clipboard.

## 🎯 Objectives

- Generate random and secure passwords.
- Allow users to customize password length.
- Provide uppercase, lowercase, numbers, and special symbols.
- Estimate password strength as Basic, Moderate, or Strong.
- Copy generated passwords with one click.
- Display useful password security tips.

## ✨ Features

- User-friendly graphical interface.
- Password length selection from 6 to 32 characters.
- Customizable character categories.
- Secure random generation using Python's `secrets` module.
- Password strength indicator.
- Copy-to-clipboard functionality.
- Password security recommendations.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **GUI Library:** Tkinter
- **Modules:** `string`, `secrets`
- **Code Editor:** Visual Studio Code

## 💻 Requirements

- Python 3 installed on your computer.
- Visual Studio Code or another Python editor.

Tkinter is generally included with Python installations. No third-party Python packages are required.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python password_generator.py
```

5. The Password Generator application will open.

## 📖 How to Use

1. Select the desired password length using the slider.
2. Choose the character categories you want to include.
3. Click **Generate Password**.
4. Check the displayed password strength.
5. Click **Copy Password** to copy the password.
6. Follow the security tips displayed in the application.

## 🔒 Security Note

The application uses Python's `secrets` module for secure random selection. The strength indicator is a basic educational estimate and does not guarantee that a password is secure against every attack. Avoid sharing generated passwords or committing real passwords to GitHub.
